# خطة التطوير — my-ikmen (Unity / Android)

## الهدف
لعبة قتال ثنائية الأبعاد لأندرويد مبنية على **Unity 6 LTS**، تقرأ موارد M.U.G.E.N / Ikemen GO
(الشخصيات `.def/.sff/.air/.cmd/.cns/.snd`، الساحات، الـ screenpack) مع تحكّم باللمس.

## القرار المعماري (ADR-001)

**الحقيقة التقنية:** محرّك Ikemen GO مكتوب بلغة Go (~125 ألف سطر في `engine/ikemen-go/src`) ولا يمكن تشغيله
داخل Unity مباشرة. كما أن Ikemen GO نفسه أصبح يملك **نسخة أندرويد رسمية منذ v1.0.0** (2026-09-12، أندرويد 13+ arm64).

| الخيار | الوصف | الحكم |
|---|---|---|
| **A — محرّك C# داخل Unity** | نعيد كتابة نواة متوافقة مع MUGEN بـ C#، ونستخدم شيفرة Ikemen GO مرجعاً | ✅ **المعتمد** (طلب المالك: Unity) |
| B — Unity واجهة + Ikemen GO كمكتبة `.so` | محرّكا رسم في تطبيق واحد، تعقيد بلا فائدة | ❌ |
| C — بدون Unity: نسخة Ikemen GO الرسمية + لمس + هوية | الأسرع (أيام) | بديل احتياطي فقط |

سنبني **نواة MUGEN 1.0 أولاً** (ما تحتاجه معظم الشخصيات)، ثم ميزات Ikemen الإضافية (ZSS، 3D، rollback) لاحقاً.

## المراحل

| المرحلة | المحتوى | معيار الإنجاز |
|---|---|---|
| **dev.1** — الهيكل | مشروع Unity 6 LTS في `unity/`، بناء APK (IL2CPP، arm64) من البيئة الآلية، مشهد فارغ | APK يعمل على جهاز Firebase الافتراضي |
| **dev.2** — قارئات الموارد | قارئ SFF v1/v2 (PCX/RLE8/RLE5/LZ5/PNG + اللوحات)، AIR، DEF، SND → Sprites / AudioClips | عارض يُظهر Kung Fu Man يتحرّك بكل حركاته |
| **dev.3** — الشخصية | مخزن الأوامر CMD، محلّل تعابير الـ triggers، آلة الحالات CNS (ChangeState، ChangeAnim، VelSet، PosAdd، HitDef …) | KFM يمشي ويقفز ويضرب بالأوامر |
| **dev.4** — القتال | لاعبان، تصادم Clsn1/Clsn2، ضرب/صد، أشرطة الحياة، الجولات، الساحة والكاميرا | جولة كاملة KFM ضد KFM |
| **dev.5** — التحكّم | أزرار لمس (عصا + 6 أزرار قابلة للتخصيص)، يد تحكّم، ذكاء اصطناعي بسيط | قتال ضد الحاسوب على الهاتف |
| **dev.6** — القوائم | الشاشة الرئيسية، اختيار الشخصية، VS، الإعدادات، الصوت، واجهة عربية | تجربة لعب كاملة من القائمة |
| **dev.7** — الإصدار | استبدال المحتوى غير التجاري (شخصيات وخطوط خاصة)، أداء Poco F3، Release على GitHub | APK قابل للتوزيع/البيع |
